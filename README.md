# PDF Separator (с поддержкой OCR)

Приложение для автоматического разделения PDF-файлов на отдельные документы (предписания) с использованием анализа номеров документов и OCR.

## 🚀 Быстрый старт

### 1. Установка системных зависимостей (ОБЯЗАТЕЛЬНО для OCR)
Так как программа работает со сканами, ей необходим движок Tesseract OCR:

1.  **Скачайте установщик Tesseract для Windows**: [UB Mannheim Tesseract](https://github.com/UB-Mannheim/tesseract/wiki).
2.  **При установке**: В разделе «Additional script data» и «Additional language data» обязательно отметьте **Russian** и **English**.
3.  **Путь установки**: По умолчанию программа ищет Tesseract по пути `C:\Program Files\Tesseract-OCR\tesseract.exe`. Если вы установили его в другое место, измените переменную `TESSERACT_CMD` в начале файла `app.py`.

### 2. Установка Python-библиотек
Запустите команду в терминале (в вашем виртуальном окружении):

```bash
pip install pymupdf pillow pytesseract
```

### 3. Запуск приложения
```bash
python app.py
```

## 📁 Организация файлов
Для удобства работы рекомендуется использовать следующую структуру:
*   **`input_folder`**: Папка для исходных PDF-файлов. Поместите сюда ваш общий пакет сканов перед выбором файла в программе.
*   **`output_folder`**: Папка, в которую программа сохранит готовые разделенные PDF-файлы (например, `doc_1492.pdf`).

## 🛠 Инструкция по использованию

1.  **Выбор PDF**: Нажмите кнопку **«Выбрать PDF»** и укажите путь к исходному файлу (рекомендуется из `input_folder`).
2.  **Папка для результатов**: Нажмите **«Выбрать папку»** и укажите директорию для сохранения (рекомендуется `output_folder`).
3.  **Разбивка**: Нажмите кнопку **«Разбить PDF»**.

## ⚙️ Как это работает

1.  **Поиск «Якорей»**: Программа сканирует каждую страницу документа. Если в верхней половине страницы найден текст `АКТ-ПРЕДПИСАНИЕ №...` или `АКТ-ПРЕДПИСАНИЕ ИД №...`, эта страница считается началом нового документа.
2.  **Формирование файлов**: Каждый документ длится от своего номера до начала следующего номера предписания.
3.  **Распознавание (OCR)**:
    *   Сначала проверяется текстовый слой.
    *   Если текст не найден (скан), используется **Tesseract OCR** с предварительной обработкой (увеличение масштаба, повышение контрастности и бинаризация).
4.  **Именование**:
    *   Если номер распознан $\rightarrow$ `doc_номер.pdf`.
    *   Если номер не найден $\rightarrow$ `doc_порядковый_номер.pdf`.

## 📦 Технические требования
- Python 3.x
- Tesseract OCR (установленный в систему)
- PyMuPDF (`pymupdf`)
- Pillow (PIL)
- PyTesseract
